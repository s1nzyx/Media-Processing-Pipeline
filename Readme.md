**сервис асинхронной обработки видео или изображений**

*суть в том что, платформа куда пользователи загружают тяжелые медиафайлы, а система отрабатывает их в фоном режиме*

***как ложиться стек:***
```
django + django rest framefork -> прием файлов, авторизация и выдача статусов обработки
```
```
celery + redis -> тяжелые воркеры которые забираю файлы из хранилища и крутят ffmpeg или pillow
```
```
sql -> хранение метаданых, история задач и профилей
```

***Как установить и пользоваться им***
*в dockerfile собран весь образ достаточно* `docker compose up --build`
